# Sitio web de Kiut Store

Archivos:
- index.html  -> estructura de la página
- style.css   -> estilos (colores, tipografía, layout)
- script.js   -> año automático en el footer

## Cómo editar lo básico
- Textos de "Sobre la marca", misión y visión: búscalos directo en index.html.
- Botón de catálogo: busca "canva.link/catalogokiut" y reemplázalo si el link cambia.
- WhatsApp: busca "50557756204" (aparece dos veces).
- Instagram: busca "kiuts_tore" (confirmar que ese es el usuario correcto).
- Colores: cambia los valores dentro de `:root{...}` en style.css.
- Fotos: reemplaza las imágenes en la carpeta por las tuyas, actualizando el atributo src en index.html.

## Cómo subirlo a un dominio
Sube los 3 archivos (index.html, style.css, script.js) a la raíz de tu hosting, en la misma carpeta, sin cambiarles el nombre.
